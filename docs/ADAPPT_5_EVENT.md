## Why NEXFIELD fits the domain

Food-system outcomes are influenced by decisions made before, during and after cultivation: crop-health monitoring, irrigation and resource planning, field operations, post-harvest quality, and market realization. NEXFIELD explores these connected decisions through six modules:

1. **Control** — farm overview and operational context.
2. **FieldSight AI** — an image-based crop-health analysis workflow.
3. **Twin** — 3D field visualization and parameterized water/yield scenarios.
4. **Intelligence** — contextual conversational interface and action presentation.
5. **Ops** — tasks and supported operational/stock workflows.
6. **Markets** — market observations and transport-cost comparisons where supported.

This is a product-scope explanation, not a claim that each data feed is live or every model is validated.

## Demo transparency

The public website is a no-login demonstration. The frontend defaults to fixture mode unless configured otherwise; local mutations are stored in the browser and are not a shared database. An optional FastAPI service contains supported inference/calculation endpoints, but a configured service and provider must be verified before calling an integration live.
