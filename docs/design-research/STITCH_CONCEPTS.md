# NEXFIELD Cinematic Design Lab: Stitch Concepts

This document references the UI mockups generated using the Stitch MCP interactive UI controller.

## Project Info
**Project Name:** NEXFIELD Cinematic Lab
**Project ID:** 8933349617585725384
**Design System:** Obsidian Agronomy (Dark Charcoal `#0e1512`, Emerald Core `#10b981`, Warm Ivory/Gold `#e9c349`).
**Typography:** Bodoni Moda (Headlines), Manrope (Body), JetBrains Mono (Telemetry/Tabular Nums).

## Screen Inventory

1. **Cinematic Homepage**
   - *Concept:* A mobile-first, full-bleed spatial digital twin background with glassmorphic layers, high-contrast editorial typography, and a radiant "Launch Interactive Demo" CTA.
   - *URL Reference:* `projects/8933349617585725384/screens/cf3a4d0897bb44c9b7d9048191628149`

2. **Minimal Navigation (Sidebar)**
   - *Concept:* Replaces the heavy top-nav with a floating left-hand glassmorphic pillar (Overview, Control, Intelligence, Spatial, Execution) over an expansive dark WebGL telemetry canvas.
   - *URL Reference:* `projects/8933349617585725384/screens/5cf99f94eebe4bfa8a8b1d7dddf78e39`

3. **Spatial Digital Twin Explorer**
   - *Concept:* A dense, 3D WebGL workstation view. Features floating scenario controllers (Irrigation, Thermal, NDVI) and a prominent pulsing hydrology risk alert over Sector 04-B.
   - *URL Reference:* `projects/8933349617585725384/screens/7bc85206f43c42748e41b7000a872677`

4. **Farm Command Center**
   - *Concept:* Operational telemetry dashboard featuring real-time dials (VPD, VWC), a tabular-num sensor matrix, and a prominent Post-Harvest Spoilage Risk alert banner.
   - *URL Reference:* `projects/8933349617585725384/screens/0742f4452d2b423ea9f7bdad54f2c96a`

5. **FieldSight Crop Inspection**
   - *Concept:* Split-pane layout. Left pane shows macro photography with Grad-CAM neural attention heatmaps. Right pane displays clinical diagnosis cards and ICAR actionable prescriptions.
   - *URL Reference:* `projects/8933349617585725384/screens/353f0b06391d48f1adb92e69735f214f`

6. **Agricultural Markets Explorer**
   - *Concept:* Split-pane comparative layout. Current farm silo inventory on the left vs. live AGMARKNET Mandi tickers and price arbitrage charts on the right. Includes a `⌘K` command palette.
   - *URL Reference:* `projects/8933349617585725384/screens/d2e382bb44f04dc38ae818d262a54797`

7. **Interactive Demo (Guided Joyride)**
   - *Concept:* A floating Joyride-style tooltip modal card ("Step 2 of 4: Deficit Irrigation") layered over a dimmed 3D digital twin, guiding the user through running a scenario simulation.
   - *URL Reference:* `projects/8933349617585725384/screens/d2a38658756d42ecbe1e1ae474bbee79`

8. **User Onboarding (Telemetry Provisioning)**
   - *Concept:* Multi-step horizontal progress tracker to sync satellite topography and provision ground sensor meshes. Features live diagnostic readouts and encrypted token fields.
   - *URL Reference:* `projects/8933349617585725384/screens/0a19f2f69fa64a87b799cc37338ee027`

These concepts serve as the visual north star for the Antigravity frontend implementation.
